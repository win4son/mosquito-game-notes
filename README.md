# 居家滅蚊遊戲筆記

第一人稱居家滅蚊遊戲（Godot 4）的開發筆記網站：遊戲總覽、蚊子行為、里程碑進度、設計決策、AI 研究助手。

國立暨南國際大學「生成式 AI」期末專案 · 學生：李志恒

- 網站：發佈後補上 GitHub Pages 網址
- 專案規則：[CLAUDE.md](CLAUDE.md)（AI 與協作者新增頁面時的唯一依據）

## 本機預覽

```bash
python3 -m http.server 8000
```

開啟 http://localhost:8000/ 。檢查規則：`python3 scripts/check_site.py`。

## 說明

這是靜態網站（純 HTML／CSS／JS，無建置步驟）。遊戲本體與完整企劃不在此 repository；網站只整理其中已確認或有紀錄的內容，並以標記區分已確認、建議、實測與示例。
